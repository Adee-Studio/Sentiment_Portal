# Sentix Enterprise - Social Text Analytics & ITPM Control Center

A unified, high-impact semester mini project combining **3 Subjects** with Indian enterprise context and advanced interactive UI:
1. **Advanced Social Text Media Analysis** (VADER Sentiment Lexicon with Indian Slang, Aspect-Based ABSA, Emotion Vectors, Live Sandbox Classifier)
2. **Enterprise System (ES)** (Role-Based Access Control, Auto-Incident Escalation Pipeline, Audit Governance, JSON/CSV Data Exporter)
3. **Information Technology Project Management (ITPM)** (Earned Value EVM Calculator in INR ₹, Interactive Gantt Schedule/WBS, Agile Kanban Board, 5x5 Risk Register)

---

## ✨ Key Features & Enhancements

- 💫 **High-Tech Animated Splash Screen:** Smooth loading screen overlay with progress bar animation on start.
- 🇮🇳 **Indian FinTech Localization:** Indian Rupee currency (INR ₹), UPI/Flipkart/Swiggy case studies, and Hinglish slang support.
- 💡 **Teacher Explanation Banners:** Built-in 1-sentence presentation helper banners on every tab.
- 📊 **Interactive EVM Panel:** Dynamic input sliders for Planned Value (PV ₹), Earned Value (EV ₹), and Actual Cost (AC ₹).

---

## 🚀 Quick Start (1-Click Run)

### Option A: Windows 1-Click Launcher (Recommended)
Double-click `run_app.bat` in the project folder. It starts the Python web server and opens the web app automatically at `http://localhost:8000`.

### Option B: Terminal Command
Run in PowerShell or Command Prompt:
```bash
python server.py
```
Then open `http://localhost:8000` in your browser.
